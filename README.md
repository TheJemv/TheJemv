## 🧑‍💻 About me

I'm a Full Stack Developer and co-founder of **Workly Services**, where I build mobile apps from the idea all the way to production. I'm currently studying **Information Technology Engineering** at Universidad Tecnológica de Matamoros.

I built and launched a mobile app on **iOS and Android**, with payments between clients and companies powered by **Stripe**, authentication with **Firebase**, and a secure **Express.js + PostgreSQL** backend running on **Google Cloud**. I'm especially interested in **mobile** and **backend** development.

## 🚀 What I've built at Workly Services

- 📱 **Mobile app** with React Native and TypeScript — live on iOS and Android
- 💳 **Payment system** between clients and companies with Stripe
- 🔐 **Login and user authentication** with Firebase
- 🛠️ **Backend API** with Express.js and PostgreSQL
- ☁️ **Cloud deployment** on Google Cloud with Cloud Run and Cloud SQL, using a private VPC so the database is never exposed to the internet
- 🧭 **Technical ownership** of every product decision, from the mobile app to the cloud infrastructure

## 🏆 Achievements

- Launched **Workly Services** on iOS and Android as co-founder and CTO
- Designed a **secure cloud architecture** on Google Cloud with a private network (VPC) for the database
